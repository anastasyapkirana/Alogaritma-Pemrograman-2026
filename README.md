## Deskripsi Program

Program ini dibuat untuk menghitung luas segitiga berdasarkan nilai alas dan tinggi yang dimasukkan oleh pengguna. Folder berisi tugas menghitung luas segitiga, yang terdiri dari program Python, dokumen laporan, dan gambar flowchart.

## Rumus

Luas segitiga dihitung menggunakan rumus:

`Luas = 0.5 × alas × tinggi`

## Input, Proses, dan Output

- **Input:** Nilai alas dan tinggi segitiga.
- **Proses:** Menghitung luas menggunakan rumus `0.5 × alas × tinggi`.
- **Output:** Hasil perhitungan luas segitiga.

## Algoritma

1. Mulai.
2. Masukkan nilai alas segitiga.
3. Masukkan nilai tinggi segitiga.
4. Hitung luas segitiga menggunakan rumus `0.5 × alas × tinggi`.
5. Tampilkan hasil luas segitiga.
6. Selesai.

## Implementasi Python

Program dibuat menggunakan Python dengan menerima input alas dan tinggi dari pengguna, mengubah input menjadi tipe data `float`, menghitung luas segitiga, lalu menampilkan hasilnya.
